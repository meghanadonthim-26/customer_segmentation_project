# Customer Segmentation Using K-Means Clustering

## Project Overview
This project focuses on segmenting customers into different groups based on their demographic and purchasing behavior. K-Means Clustering is used to identify customers with similar characteristics.

## Objective
The main objective is to:
- Analyze customer data
- Identify different customer groups
- Understand customer purchasing behavior
- Visualize the identified segments

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Methodology
1. Created and loaded the customer dataset
2. Selected relevant customer features
3. Standardized the data using StandardScaler
4. Applied K-Means clustering
5. Created 4 customer segments
6. Visualized the segments using a scatter plot
7. Analyzed the characteristics of each segment

## Features Used
- Age
- Annual Income
- Annual Spending
- Purchases Per Year
- Website Visits Per Month

## Result
The K-Means algorithm successfully grouped customers into four different segments based on their similarities in income, spending, purchasing frequency, and website activity.

## Conclusion
Customer segmentation helps businesses understand different types of customers and their behavior. The insights obtained from clustering can be used for targeted marketing and personalized customer strategies.

## Tools
Google Colab was used for developing and executing the Python code.
